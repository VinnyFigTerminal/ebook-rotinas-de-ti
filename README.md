# Seu plantão termina. A operação continua.

eBook para equipes de TI que precisam transformar tarefas recorrentes em procedimentos que outra pessoa consegue executar. O guia traz um exemplo completo de diagnóstico de fila de impressão, um modelo copiável e um checklist de revisão.

- **[Ler o eBook online](./leitura.md)** — versão que se adapta à largura da tela no GitHub.
- **[Abrir o eBook diagramado em PDF](./Seu_Plantao_Termina.pdf)** — edição com capa, sumário clicável e cinco capítulos.
- **[Consultar os prompts](./prompts.md)** — planejamento, redação, diagramação e revisão.

O cenário e o procedimento de exemplo são fictícios. O projeto foi desenvolvido como exercício de escrita e design editorial com IA.
